  \item {
    Geben sind die vier folgenden Aussagen über reguläre Sprachen.
    Entscheiden Sie jeweils, ob diese Aussagen wahr oder falsch sind und geben
    Sie eine Begründung an.

    \begin{enumerate}
      \setlength\itemsep{10pt}
      \statement{
        Wenn es bei einem NFA mindestens einen Übergang gibt, sodass das gelesene
        $w \in \Sigma{^*}$ in einem verwerfenden Zustand landet,
        so akzeptiert der NFA $w$ nicht.
      }{false}{
        Dies ist nicht korrekt, denn ein NFA funktioniert genau andersherum.
        Definitionsgemäß gilt, dass ein NFA $w \in \Sigma^*$ akzeptiert,
        wenn es einen Übergang von $w$ gibt, sodass $w$ in einem akzeptierenden
        Zustand landet.
      }
      \statement{
        Ein minimaler NFA hat höchstens so viele Zustände wie ein DFA,
        der die gleiche Sprache entscheidet, mit minimaler Anzahl an Zuständen.
      }{true}{
        Dies stimmt, da ein NFA genauso mächtig ist wie ein DFA und höchstens
        Zustände sparen kann.
        Ein minimaler NFA kann also weniger Zustände besitzen als ein minimaler DFA,
        aber entsprechend besitzt ein minimaler NFA höchstens so viele Zustände
        wie ein äquivalenter minimaler DFA.
      }
      \statement{
        Sei $k \in \mathbb{N}$ beliebig, aber fest.
        Jede Sprache, die nur Wörter der Länge $k$ akzeptiert, ist regulär.
      }{true}{
        Dies ist ebenfalls korrekt, da für solch eine Sprache z.B.
        alle akzeptierten Wörter explizit durch eine endliche Anzahl an
        Zuständen kodiert werden könnte.
      }
      \statement{
        Jede nicht reguläre Sprache kann durch das Pumping-Lemma auch als solche
        identifiziert werden.
      }{false}{
        Dies ist nicht korrekt, denn es gilt lediglich die Implikation:
        Wenn die Sprache $L$ regulär ist, erfüllt $L$ das Pumping-Lemma.
        Dadurch folgt nicht automatisch: Wenn $L$ nicht regulär ist,
        gilt das Pumping-Lemma nicht.
        Es gibt also auch nicht reguläre Sprachen, die trotzdem das Pumping-
        Lemma erfüllen.
      }
    \end{enumerate}
  }
  \newpage
  \item {
    Beweisen Sie mit Hilfe des Pumping-Lemmas, dass folgende Sprache über dem
    Alphabet $\Sigma = \{a, b\}$ nicht regulär ist:

    \[
      L = \{w \in \Sigma ~| ~|w|_a = |w|_b + 1\}
    \]
    \solution{
      \doublespacing

      Sei $n \in \mathbb{N}$ die vom Pumping-Lemma gegebene Schranke.
      Sei $z = a^{n}b^{n+1} \in L$, $|z| \geq n$.

      $\Rightarrow$ Es existiert eine Zerlegung $z = uvw$ mit $|uv| \leq n$ und $|v| \geq 1$.

      Nach Definition von $z$ besteht $v$ nur aus $a$. $\Rightarrow$ $v = a^k, 1 \leq k \leq n$.

      $\Rightarrow z = uvw = a^{j-k}a^{k}a^{n-j}b^{n+1} = a^{j-k+k+n-j}b^{n+1} = a^{n}b^{n+1} \in L, k \leq j \leq n$.

      Nach Pumping-Lemma $z' = uv^{i}w \in L$ für $i \in \mathbb{N}_0$.
      Sei $i=2 \in \mathbb{N}_0$.

      $\Rightarrow z' = uv^{2}w = a^{j-k}a^{k}a^{k}a^{n-j}b^{n+1} = a^{n+k}b^{n+1} \notin L$ \Large\lightning\normalsize

      $\Rightarrow L$ ist nicht regulär. $\Box$
    }{}
  }
\end{enumerate}
